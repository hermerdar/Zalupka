# Streamer.bot Overlay Manager

Node.js-прослойка между **Streamer.bot** (события Twitch) и **OBS**. Даёт:

- **Один источник для OBS** — одна ссылка `http://localhost:4848/overlay`, которую ты добавляешь как **Browser Source**. Все алерты идут через неё.
- **Менеджер (веб-панель)** на `http://localhost:4848/` — включать/выключать алерты, менять текст/цвет/длительность, тестировать их на лету.
- **Система виртуальной валюты** (отдельно от баллов канала) с хранением в **SQLite**: зрители получают валюту за время в чате и за события (sub, raid, cheer и т.д.). Балансами можно управлять вручную из панели.

## Как это работает

```
Twitch ──► Streamer.bot ──(WebSocket)──► Overlay Manager (Node.js) ──► OBS Browser Source (оверлей)
                                              │
                                              └──► SQLite (пользователи + валюта) + веб-панель управления
```

Прослойка подключается к **WebSocket-серверу Streamer.bot** как клиент, подписывается на Twitch-события, нормализует их и:
1. начисляет виртуальную валюту по настроенным правилам;
2. отправляет красивый анимированный алерт на оверлей (если этот тип включён);
3. показывает событие в живой ленте панели.

## Требования

- Node.js 18+ (разрабатывалось на v22).
- Streamer.bot с включённым **WebSocket Server** (Servers/Clients → WebSocket Server). По умолчанию `127.0.0.1:8080`.
- OBS (Browser Source).

## Установка

```bash
npm install
cp .env.example .env   # при необходимости поправь порты
npm start
```

После запуска в консоли появятся ссылки:

```
Manager:  http://localhost:4848/
Overlay:  http://localhost:4848/overlay   <- добавить как OBS Browser Source
```

## Быстрый запуск на Windows (без команд)

1. Установи **Node.js** LTS с https://nodejs.org (галочку «Add to PATH» оставь включённой).
2. Скачай проект: на странице репозитория **Code → Download ZIP** и распакуй (например, в `E:\Zalupka`).
3. Дважды кликни по **`start.bat`** — он сам создаст `.env`, поставит зависимости (один раз) и запустит приложение. Окно не закрывай, пока стримишь.

## Настройка Streamer.bot

1. В Streamer.bot открой **Servers/Clients → WebSocket Server** и включи его (Enabled).
2. Запомни **Address** и **Port** (по умолчанию `127.0.0.1` и `8080`).
3. Пропиши их в `.env` (`STREAMERBOT_HOST`, `STREAMERBOT_PORT`). Если включена аутентификация — задай `STREAMERBOT_PASSWORD`.
4. Убедись, что Streamer.bot подключён к Twitch и события приходят. В панели индикатор **Streamer.bot** станет зелёным.

## Настройка OBS

1. Добавь источник **Browser** (Браузер).
2. URL: `http://localhost:4848/overlay`
3. Размер: под разрешение сцены (например, 1920×1080). Фон оверлея прозрачный.
4. Готово — все включённые алерты будут появляться поверх трансляции.

## Переменные окружения (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `4848` | Порт веб-сервера (панель + оверлей) |
| `STREAMERBOT_HOST` | `127.0.0.1` | Хост WebSocket-сервера Streamer.bot |
| `STREAMERBOT_PORT` | `8080` | Порт WebSocket-сервера Streamer.bot |
| `STREAMERBOT_ENDPOINT` | `/` | Endpoint WebSocket-сервера |
| `STREAMERBOT_PASSWORD` | — | Пароль, если включена аутентификация |
| `DB_PATH` | `./data/app.sqlite` | Путь к файлу базы SQLite |

## Виртуальная валюта

- **За время в чате**: каждые 60 секунд активные зрители (написавшие в чат в пределах «окна активности») получают `perMinute` валюты.
- **За события**: настраиваемые награды за follow / sub / resub / подарочные подписки (за штуку) / raid / cheer (за бит) / награды за баллы / сообщение в чате.
- **Вручную**: в разделе «Пользователи» можно начислять и списывать валюту, искать и сортировать пользователей.

Все настройки (алерты + валюта) хранятся в таблице `settings` в SQLite и переживают перезапуск.

## Поддерживаемые события Twitch

`Follow`, `Cheer`, `Sub`, `ReSub`, `GiftSub`, `GiftBomb`, `Raid`, `RewardRedemption` (баллы канала). `ChatMessage` используется для учёта активности и начисления валюты за время.

## Структура проекта

```
src/
  server.js       точка входа: Express + WebSocket + статика
  config.js       конфиг из .env
  db.js           SQLite: пользователи, транзакции, настройки
  defaults.js     дефолтные алерты и настройки валюты
  hub.js          pub/sub для overlay/manager WebSocket-клиентов
  streamerbot.js  подключение к Streamer.bot и нормализация событий
  alerts.js       конфиги алертов + отправка на оверлей
  currency.js     движок валюты (время в чате + награды за события)
  routes.js       REST API для панели
public/
  manager/        веб-панель (дашборд, алерты, валюта, пользователи)
  overlay/        страница оверлея для OBS Browser Source
```

## API (кратко)

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/status` | Статус, статистика, настройки валюты |
| GET | `/api/events` | Последние события (лента) |
| GET/PUT | `/api/alerts`, `/api/alerts/:type` | Чтение/изменение алертов |
| POST | `/api/alerts/:type/test` | Тестовый алерт на оверлей |
| GET/PUT | `/api/currency` | Настройки валюты |
| GET/POST | `/api/users`, `/api/users/:id/adjust` | Пользователи и корректировка баланса |

WebSocket: `/ws/overlay` (для OBS) и `/ws/manager` (для панели).
